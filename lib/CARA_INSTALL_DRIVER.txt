====================================================
  CARA MENAMBAHKAN DRIVER MySQL JDBC
====================================================

1. Download MySQL Connector/J dari:
   https://dev.mysql.com/downloads/connector/j/
   Pilih "Platform Independent" → download file ZIP

2. Ekstrak ZIP → ambil file bernama:
   mysql-connector-j-x.x.x.jar

3. Rename (ganti nama) file tersebut menjadi:
   mysql-connector.jar

4. Copy file mysql-connector.jar ke folder ini (lib/)

5. Buka NetBeans, lakukan Clean and Build (Shift+F11)
   lalu Run (F6)

====================================================
  ATAU melalui NetBeans GUI:
====================================================
1. Klik kanan pada project "pemrograman2" di Projects panel
2. Pilih Properties → Libraries
3. Klik "Add JAR/Folder"
4. Pilih file mysql-connector-j-x.x.x.jar yang sudah di-download
5. OK → Close → Clean and Build
